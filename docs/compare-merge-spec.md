## 0. 文档说明

本规格书定义 Chrome-Markdown-Edit 的「对照/合并」界面功能。它是后续代码实现的唯一事实源（single source of truth）。在当前阶段仅做功能定义，不涉及代码改动；代码改动须待用户明确指令。

---

## 1. 目标与范围

### 1.1 是什么

一个**离线、纯本地**的「多文件并排对比 + 差异编辑 + 移动块检测」工具。把两份或三份本地 Markdown/文本文件并排摆开，逐行标出哪里不同，支持行内字词级高亮、移动块检测（用连线标识），并允许用户在任意一栏直接编辑，保存即得到最终文件。

### 1.2 不是什么

- 不碰 Git、不联网、不上传。
- 不是 Git 三路合并器（不会自动合非冲突、只留冲突）。
- 不存在「自动拼终稿」的中间画布——中栏是一份真实持久的文件。

### 1.3 技术底座与能力边界

| 能力 | 由谁提供 | 说明 |
|---|---|---|
| 三栏/两栏骨架 | `@codemirror/merge` 的 `MergeView` | 提供多文档并排、行级 diff、基础合并交互 |
| 行级 diff | `MergeView` 内置 | 逐行比较，标注新增/删除/修改 |
| 行内字词级高亮 | **自研**（`ViewPlugin` + `Decoration`） | CodeMirror 合并视图不原生支持，需对比相邻行 token 自行绘制 |
| 移动块检测与连线 | **自研**（行指纹算法 + `StateField` + 画布） | CodeMirror 无此能力，完全自研 |
| Location Pane | **自研** 独立小部件 | 缩略概览 + 移动块连线 |

## 2. 模式定义

### 2.1 两栏模式（Two-Pane）

- **左栏 = 文件 A**，**右栏 = 文件 B**。
- 两份文件都**完整显示、不折叠、都可编辑**。
- 差异在左右两栏之间标识（行背景色 + 行标 + 行内字词高亮）。
- 用户可改左栏、也可改右栏；保存的是用户当前活动栏对应的文件。

### 2.2 三栏模式（Three-Pane）

- **左栏 = 文件 A**，**中栏 = 文件 B**，**右栏 = 文件 C**——三份平级独立文件。
- 三份文件都**完整显示、不折叠、都可编辑**。
- 差异在**相邻栏之间**标识：左↔中、中↔右分别各自比对。
- **中栏语义澄清**：参照用户上传图里的「Result」栏位置，但本项目的中栏是一份**真实持久的文件**（用户选择或新建），可直接编辑，也可以接受左栏/右栏的某个差异块进入——它不是自动拼接的临时画布，也不存在「从零拼终稿」的概念。

## 3. UI 布局（参照用户上传图）

整体布局自上而下分四个区：**顶部信息/工具栏区 → 主体编辑区 → Location Pane → 底部操作栏**。忽略参考图的暗色主题与黑色背景，仅取功能结构与交互元素。

### 3.1 顶部信息/工具栏区

| 元素 | 来源（参考图） | 本项目实现 |
|---|---|---|
| 标题栏 | `Merge Revisions for <文件路径>` | 显示当前对比的主文件名/路径 |
| 差异统计 | `6 changes, 2 conflicts` | 实时统计：变更块数、冲突块数（三栏取相邻栏并集） |
| 应用非冲突变更 | `Apply non-conflicting changes` | 一键把无冲突差异块自动接受（可选，默认关闭） |
| 显示范围下拉 | `Left` / `All` / ... | 仅看左栏差异 / 看全部 / 仅看右栏差异 |
| 过滤下拉 | `Do not show` | 隐藏已解决/已忽略的块 |
| 高亮粒度 | `Highlight words` | 切换行级高亮 / 字词级高亮 |
| 图标按钮组 | 刷新、导航、空白差异、设置 | 对应工具栏图标 |

### 3.2 主体编辑区

- 每个栏含：**栏标题**（角色标签 + 文件路径）+ **行号** + **语法高亮** + **同步滚动** + **可编辑**。
- 两栏/三栏通过工具栏按钮切换。
- 三栏时三份文件滚动保持逻辑行对齐。

### 3.3 差异与冲突可视化

- **行背景色**：
  - 浅红色 = 删除 / 修改前的内容
  - 绿 = 新增 / 修改后的内容
  - 蓝 = 移动块（见第 6 节）
- **行内字词级高亮**：精确标出同一行里具体改了哪个词（不是整行涂色）。
- **黄色侧边条**：标识有差异的行范围，便于快速扫视。
- **差异块操作小图标**：每个差异块旁有 `× >`（拒绝/忽略）、`× <`（接受）等小按钮。
- **连接线 / 箭头**：左右（或相邻栏）差异块之间绘制连接线，辅助眼球定位。

### 3.4 Location Pane（位置概览）

- 位于编辑区侧边（参考 WinMerge 的 location pane），是一个**迷你缩略图**。
- 用色块显示**全文差异分布**（红/绿/蓝小条）。
- **移动块的连线在此绘制**：从源位置到目标位置的蓝色连线，直观呈现「这段从这里移到了那里」。
- 点击色块/连线可跳转到对应位置。

### 3.5 底部操作栏

| 按钮 | 作用 |
|---|---|
| `ACCEPT LEFT` | 接受左栏当前差异块到活动目标栏 |
| `ACCEPT MIDDLE` | 接受中栏当前差异块（三栏） |
| `ACCEPT RIGHT` | 接受右栏当前差异块 |
| `APPLY` | 把当前活动栏内容写回其对应文件 |
| `ABORT` | 放弃本次对照，不保存 |

## 4. 工具栏（与主编辑器一致）

对照/合并界面应提供与单文件编辑窗口**一致**的完整工具栏，至少包含：

1. 打开文件（分别为左/中/右栏选择文件）
2. 保存 / 另存为
3. 撤销 / 重做
4. 查找 / 替换
5. 格式化按钮组：加粗 / 斜体 / 高亮 / 颜色 / 字号（保留现有编辑器按钮，不得隐藏，呼应项目铁律）
6. 上一差异 / 下一差异
7. 展开 / 折叠所有差异（**默认展开**，不折叠相同内容）
8. 显示 / 隐藏行内差异高亮
9. 显示 / 隐藏空白差异
10. 切换两栏 / 三栏模式
11. 块移动检测开关

## 5. 差异显示

### 5.1 行级差异

由 `MergeView` 内置提供：逐行比较，标注新增 / 删除 / 修改，行号旁打 `−` / `+` / `±`。

### 5.2 行内字词级差异

- **自研层**：对每一对「修改前行 / 修改后行」做 token 级对比（基于编辑距离 / Myers 变种的字词比对）。
- 仅在被标记为「修改」的行内绘制字词高亮，精确标出增删的词。
- 高亮粒度可由顶部 `Highlight words` 下拉切换（行级 / 字词级）。

### 5.3 颜色方案

- 浅红色 = 删除 / 修改前；绿 = 新增 / 修改后；蓝 = 移动块。
- 颜色必须跟随主编辑器主题（含护眼豆沙绿等皮肤），不得在暗色/亮色主题下不可读。

---

## 6. 块移动检测（Move Detection）—— 新增核心能力

目标对齐 WinMerge 的 move block detection。

### 6.1 定义

当**同一段连续内容**在文件中（或跨相邻栏之间）出现在**不同位置**，且内容实质相同、仅位置不同，判定为「移动块」，而非「删除 + 新增」。

### 6.2 算法（自研）

1. **行指纹**：对每段连续行计算哈希 / 归一化指纹（忽略空白差异可选）。
2. **跨位置匹配**：在同一文件内或相邻栏之间，寻找指纹相同但位置不同的块。
3. **排除冲突**：已从行级 diff 命中（真实增删改）的行不参与移动判定，避免重复标记。
4. **阈值**：连续行数 ≥ 设定阈值（如 ≥ 2 行）才视为块，避免噪声。

### 6.3 可视化

- 移动块用**蓝色背景**标识（区别于红/绿的行级差异）。
- 在源位置与目标位置之间绘制**蓝色连接线**（主体区侧边 + Location Pane 内）。
- 顶部统计增加「移动块数」维度（可选）。

### 6.4 移动块编辑

- **导航**：上一移动块 / 下一移动块 按钮与快捷键，在移动块之间跳转。
- **高亮**：当前移动块高亮强调，连接线加粗。
- **Location Pane 连线**：移动块的源→目标连线在 Location Pane 中显示，点击跳转。

---

## 7. 差异块操作

- **接受左 / 接受右 / 接受中**：把当前差异块内容写入活动目标栏的对应位置（覆盖目标栏该块）。
- **拒绝 / 忽略**：标记该块为已处理、不采纳，从「待处理」列表移除（不改变内容）。
- **小箭头图标**：每个差异块旁提供一键 `接受` / `拒绝` 图标（参考图 `× >` / `× <`）。
- **快捷键**：`B` / `]` 在块间跳转（`Alt+B` 在编辑区内）；接受/拒绝快捷键待定。

## 8. 保存行为

- **活动栏概念**：用户最后点击/聚焦的栏即为「活动栏」。
- **保存按钮（`APPLY` / 工具栏保存）**：保存**活动栏**内容到其对应文件。
- **另存为**：指定输出路径，不覆盖原文件。
- **导出 diff（保留）**：生成 `.diff` 文本清单（`@@ -a,b +c,d @@` 格式），作为修订留痕，独立于保存逻辑。

> 明确纠正旧逻辑：两栏模式下「导出结果」不再默认取右栏内容；保存必须显式指向活动栏。

## 10. 技术实现要点（CodeMirror 6）

1. **骨架**：复用 `@codemirror/merge` 的 `MergeView` 搭两栏/三栏，降低基础比对成本。
2. **行级 diff**：由 `MergeView` 提供，无需自研。
3. **行内字词高亮**：自研 `ViewPlugin` + `Decoration`，对比相邻修改行的 token 序列，绘制字词级装饰。
4. **移动块检测**：自研算法（见 6.2），结果存入 `StateField`；用装饰 + 画布连线渲染。
5. **Location Pane**：独立 DOM 小部件 + `<canvas>` / SVG 连线，监听 EditorView 滚动与状态变化重绘。
6. **同步滚动**：`MergeView` 已支持多栏对齐，需验证三栏（A/B/C）逻辑行对齐无偏移。
7. **主题适配**：所有装饰颜色走 CSS 变量，跟随主编辑器 `--editor-theme` 等维度。

## 12. 已确认决策纪要（用户 2026-08-08 拍板）

1. **三栏语义**：确认采用「平级三文件（A/B/C）」模型，不改为 base/ours/theirs。
2. **移动块检测性能阈值（由实现方推荐）**：
   - 判定为移动块的硬阈值：连续行数 ≥ 2 行 **且** 块内非空字符数 ≥ 20（对齐 Git `--color-moved=blocks` 的 20 字符下限）。
   - 大文件降级策略：当任一文件行数 > 5000 行时，移动块候选上限 200 个；超出则只做高亮、不绘制连线，避免 O(N²) 卡顿。
   - 指纹归一化：忽略行首尾空白；空白差异默认不计入移动判定（与「显示/隐藏空白差异」开关联动）。
3. **README 修订**：随本次改造一并修订过时描述（单栏 unified 视图、presentableDiff 等）。
4. **应用非冲突变更**：默认关闭，由用户显式触发。
5. **颜色修正**：原「红 = 删除/修改前」修正为「浅红色 = 删除/修改前」（见 3.3、5.3）。

## 13. 可移植方案调研结论（GitHub 全仓搜索，2026-08-08）

### 13.1 行内字词级差异

- **`udamir/api-diff-viewer`** 提供完整 CodeMirror 6 实现：
  - `src/codemirror/extensions/inline-word-diff.ts`：基于 `diff` 包（`diffWords` / `diffChars`），用 `StateField` + `ViewPlugin` + `Decoration` 在修改行内绘制增删字词（`cm-inline-diff-added` / `cm-inline-diff-removed`）。
  - `src/codemirror/extensions/word-diff.ts`：`computeWordDiff(before, after, mode)` 返回 `beforeRanges` / `afterRanges`，可直接喂给两侧面板。
- **移植方式**：移植这两个文件 + 主题（`.cm-diff-word-added` 等走 CSS 变量），由本项目 diff 引擎提供 `beforeContent` / `afterContent` 行映射。

### 13.2 块移动检测

- **Git `--color-moved=blocks` 算法**（参考 github.blog / mfoconsulting 文档）：对行级 diff 的「删除块」与「新增块」做内容指纹匹配，相同者标记为 moved；阈值 ≥ 20 字符。
- **`chennan47/wikEdDiff`**（Public Domain）：唯一能检测块移动的 JS 库，提供 `blockMinLength=3`（词级）、`unlinkBlocks`、`recursiveDiff` 等可调参数，作为算法细节参考（其 HTML 渲染模型不直接复用，匹配/阈值思路可借鉴）。
- **自研落点**：在本项目行级 diff 之上叠加「删除块 ↔ 新增块」指纹匹配层，输出移动块对，存入 `StateField`，供装饰与连线消费。

### 13.3 Location Pane（位置概览）

- **`@replit/codemirror-minimap`**（v0.5.2，MIT，Replit 出品）：提供 `showMinimap` facet，支持 `gutters: Array<Record<lineNumber, color>>` 按行号标记差异色块，以及 `showOverlay` 视口指示。
- **移植方式**：以该包为基底显示差异分布；在其 `create` 返回的容器上**叠加自研 SVG 层**绘制移动块源→目标连线（主体编辑区侧边连线同理）。
- 该包为 CodeMirror 6 专用 peer deps，已与本项目 `@codemirror/*` 6.x 兼容。

### 13.4 技术栈确认

- 浏览器侧：WXT + MV3 + CodeMirror 6（`@codemirror/merge` 6.12）。
- EXE 侧：Tauri 2（`desktop/` 已确认），webview 复用同一套前端 `src/compare*.js`，文件读写经 `tauri-plugin-fs` 命令适配（与浏览器侧 `File` API / `chrome.storage` 分流）。**核心实现双端复用同一份前端代码**。
